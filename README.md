## 🔬 Bolsista de Iniciação Científica

> **GeoVisualização e Análise de Risco de Acesso a Recursos de Saúde com Aprendizado de Máquina**
> Pontifícia Universidade Católica de Minas Gerais (PUC Minas)
> Orientação: Prof. Sandro Laudares

Pesquisa na interseção entre geoprocessamento, dados de saúde e machine learning, investigando como visualizar e prever risco de acesso a recursos de saúde em diferentes regiões.

- 🧠 Estudando o stack Python de ciência de dados: **scikit-learn, pandas, NumPy, PyTorch**

- 🐧 Usuário de Linux, entusiasta de sistemas e tópicos de baixo nível
